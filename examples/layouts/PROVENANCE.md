# Layout provenance

main-pr.json derives from Herdr Desktop 0.1.16 main layout, cloned using
layout.clone and modified by Jacobo de Vera in 2026 for the standalone PR status badge
and panel with its integrated toggle. Stock tabs and workspace-status mods remain
unchanged; extra controls occupy adjacent layout blocks. Apache-2.0; see LICENSE.
Upstream: https://github.com/herdrdev/herdr-app

Local modifications: The bottom region now offers a stock/custom stack and switch.
The custom bar composes standalone-compatible status mods through Status Bar API v1.
The original stock bar, tab strip and other panels remain referenced unchanged.
